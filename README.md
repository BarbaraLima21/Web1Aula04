# Web1Aula04

Nesta aula, aprendemos sobre como estruturar páginas HTML, também aprendemos a diferença entre elementos de bloco e linha, como organizar o conteúdo usando DIV e aplicar estilos básicos com CSS. Também aprendemos a utilizar tags semânticas como HEADER, NAV, MAIN, SECTION, ARTICLE, ASIDE e FOOTER para deixar o site mais organizado e compreensível.
